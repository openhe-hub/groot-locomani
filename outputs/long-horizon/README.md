厨房回合使用 Kimodo 根据骨盆路点和朝向生成的三段步态。G1 将餐篮水平移动 2.08 米，最大抬升 28.0 厘米。关灯后复核了餐篮支撑和盒盖状态。[厨房详情及路点](kitchen-close-down/README.md) · [阶段记录](kitchen-close-down/evidence/events.json) · [实测结果](kitchen-close-down/evidence/metrics.json)

**配发车间。** 工帽由 G1 搬运 1.70 米后放稳到车上。G1 转动选择器，触读 `PPE-17`、`QA-B4`、`DOCK-02` 三张料签后按键放行。电机驱动带载台车沿导轨移动 68.7 厘米。出库读头在 8.5 厘米处读到 `DISPATCH-PPE-17`，连续 40 个控制步的记录确认台车到位、工帽仍受托盘支撑且 G1 在场。原运行在写终点汇总 JSON 时发生序列化错误，实测结果已从实时回执和原始状态复核恢复。[预览](workwear-dispatch/preview.jpg) · [阶段记录](workwear-dispatch/evidence/events.json) · [实测结果](workwear-dispatch/evidence/metrics.json)

两个回合均在 L40S 主机的物理 GPU 1 上运行，同一件货物跨工序保留其物理状态。GR00T N1.7 在线读取实时头部图像负责抓取和起运（厨房 18 次查询，工厂 13 次），合手并检测到手指接触后使用弹簧阻尼抓持辅助。厨房载篮时复用此前实跑的腰臂姿态，工厂载货步行参考来自实跑的 GR00T 运动。SONIC 依据当前机器人状态跟踪各自的参考；对位放手、拨动机构、擦拭和读签使用场景状态反馈。录像按每两个 50 Hz 控制步取一帧，在原场景以原速 25 fps 重渲染，全景和操作特写同步。工厂最后一次回执位于第 3,107 个控制步，仿真用时 62.14 秒，25 fps 视频包含 1,554 帧（62.16 秒）。这些数字对应各自交付的固定场景回合。

每个任务目录保留成片与预览，轨迹、测量和运行配置集中在 `evidence/`。工厂的[终点复核回执](workwear-dispatch/evidence/verified-terminal.json)保留了出库读头的原始判据。
