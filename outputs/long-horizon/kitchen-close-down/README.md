# 厨房餐后收尾 · Kimodo 骨盆路点版

[三栏全程录像](https://github.com/openhe-hub/groot-locomani/releases/download/media-v1/kitchen-close-down.mp4) · [输入路点、朝向和提示词](evidence/waypoint-plan.json) · [工序事件](evidence/events.json) · [验收结果](evidence/metrics.json)

G1 从一次环境复位连续执行至关灯后复核。仿真共 3,349 个控制步，66.98 秒，骨盆水平累计行走 9.12 米。25 fps 录像共 1,675 帧，媒体时长 67.00 秒。中栏的空心圆是送入 Kimodo 的骨盆路点，绿线是机器人实走路径。SOMA 人形从同一控制步的机器人姿态重定向。

**控制和输入来源**　GR00T N1.7 在取篮阶段调用 18 次，检测到手指接触后启用原任务的弹簧阻尼抓持辅助。三段行走均重新运行 Kimodo-G1-RP-v1（种子 42），输入包括动作说明、时长、骨盆平面路点和转身／停靠朝向。路点来源是固定房间布置和前一条成功轨迹；返回水槽的末点根据调试中观察到的停靠误差向前调整了 16 厘米，侧向调整了 6.4 厘米。SONIC 读取新生成的基座及腿部参考做 50 Hz 跟踪。载篮时腰臂另取自原演示的持物姿态序列；工位操作使用指尖 IK，必要时由实测去程步态生成短停靠步。接触、物体位置及工序完成条件均在本回合的物理仿真中测量。

**结果边界**　这是调试后的一个成功回合。[开发回合记录](evidence/development-runs.json)保留了各次运行结局。长程调试中出现过放篮停滞、篮子被后续动作碰落和擦板超出可达范围。交付回合使用原版平面餐边台、盒盖与沥水板资产，三者与原演示逐文件一致。严格的有／无骨盆路点对照见[按泵试验](../../kimodo/pelvis-waypoints/README.md)。

原始回合保存在远端工作目录的 `long-horizon-work/experiments/pelvis-input/kitchen-08`，运行使用物理 GPU 1。[复跑说明](../../../examples/g1_loco_manipulation/long_horizon/README.md)
